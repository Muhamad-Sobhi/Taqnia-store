# Layout Components

- **Purpose:** Define the home for store-wide header, navigation, footer, and shell components.
- **Audience:** Frontend developers and AI agents.
- **Last updated:** 2026-11-24
- **Related docs:** [Design system](../../../../../docs/design/design-system.md), [Accessibility](../../../../../docs/design/accessibility.md)

Layout components provide the store header, responsive navigation, product search, locale links, and footer for the `/en` and `/ar` routes. The header search retains a single current query for refinement, and locale switching preserves query parameters. Keep all navigation accessible and emphasize shopping rather than corporate storytelling.

# UI Primitives

- **Purpose:** Define the home for reusable, accessible low-level components.
- **Audience:** Frontend developers and AI agents.
- **Last updated:** 2026-11-24
- **Related docs:** [Design system](../../../../../docs/design/design-system.md), [Accessibility](../../../../../docs/design/accessibility.md)

Current primitives:

- `Button`: primary and secondary actions, native button semantics, and disabled state.
- `Container`: shared responsive page width with standard div attributes.
- `SkipLink`: keyboard-visible link to the main content landmark.

Document props, states, keyboard behavior, and usage for new primitives. Check existing components before adding dependencies.

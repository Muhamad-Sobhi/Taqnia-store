# Components

- **Purpose:** Explain where reusable store UI belongs.
- **Audience:** Frontend developers and AI agents.
- **Last updated:** 2026-11-24
- **Related docs:** [Design system](../../../../docs/design/design-system.md), [Accessibility](../../../../docs/design/accessibility.md)

Place primitives in `ui/`, product/cart/account features in `features/`, and global navigation/footer in `layout/`. Keep client components small and do not put business logic or hard-coded user-facing copy here.

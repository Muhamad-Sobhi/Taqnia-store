# API Routes

- **Purpose:** Contain thin Next.js Route Handlers for external/browser requests.
- **Audience:** Backend and frontend developers.
- **Last updated:** 2026-11-24
- **Related docs:** [Store API](../../../../../docs/api/store-api.md), [Security](../../../../../docs/engineering/security.md)

Validate inputs with Zod, call server services, and map typed results/errors to HTTP responses. Keep business logic and database access out of route handlers.
